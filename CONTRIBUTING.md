# Contributing

MediAmi's source code is private, so **pull requests with code are not accepted**. Reports, ideas
and feedback are very welcome, and they shape what gets built.

## Before you post anything

**Never include any of these in an issue, discussion, comment or screenshot:**

- API keys or tokens
- Server URLs, hostnames or IP addresses (including `192.168.x.x`)
- Names of private libraries or titles you would rather not share

Blur or crop screenshots, and edit logs before pasting them. If you pasted something by mistake,
edit the post right away and rotate the key in your service's settings.

## Reporting a bug

Use the **Bug report** form. The more of these you give, the faster it can be fixed:

- MediAmi version (Settings → About) and whether it is the Mac or iPad app
- macOS or iPadOS version
- Which service is involved (Radarr, Sonarr, Lidarr, SABnzbd, Overseerr/Jellyseerr) and its version
- Steps to reproduce, what you expected and what happened
- Whether it also happens in Demo Mode

Search existing issues first; add a 👍 or a detail to an existing one instead of opening a duplicate.

## Suggesting a feature

Use the **Feature request** form, or start a Discussion if the idea is still rough. Say what you
are trying to do, not only the feature you imagine: it helps find the best solution.

## Questions

Use [Discussions](../../discussions) rather than issues. Issues are for bugs and concrete requests.

## Security

Never report security problems in public. See [SECURITY.md](SECURITY.md).

Please be kind and constructive. Posts that are abusive or off-topic may be removed.
