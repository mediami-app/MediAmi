# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub:
**[Security → Report a vulnerability](../../security/advisories/new)**.

Include what you found, the app version and platform (Mac or iPad), and the steps to reproduce.
Do not include real API keys, server URLs or IP addresses; describe them instead.

You can expect an acknowledgement within a few days. Once the problem is fixed and released, the
advisory can be published with credit to you, if you want it.

## Scope

In scope: the MediAmi app for Mac and iPad, and how it stores and sends your credentials.

Out of scope: vulnerabilities in Radarr, Sonarr, Lidarr, SABnzbd, Overseerr or Jellyseerr
themselves (report those to their own projects), and problems that need physical access to an
unlocked device.

## Supported versions

Only the latest released version receives fixes.
